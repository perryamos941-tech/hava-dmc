# HAVA 業主資訊平台 v2.2 — 售樓說明書圖則及機電表修正版

## 更新內容

1. **機電配置房間位置修正** — PDF 111–119頁（印刷109–117頁）的房間名稱以表格左欄合併儲存格的實際水平分界重新配對，修正原版錯用「距離最近的房間標籤」而造成的錯配。例如 PDF 第112頁「隱蔽式花灑器 Concealed type sprinkler」位於廚房／開放式廚房，不是主人浴室。新舊比較有263筆記錄的房間分類實際改動（另有純格式統一）。**數量欄仍屬PDF文字位置擷取，未逐格人工認證。**
2. **露台／工作平台平方呎** — 於原平方米數字後加上平方呎。依售樓說明書註明的 1 平方米 = 10.764 平方呎，四捨五入至整數；如 1A 15樓 A 室的露台 2.000 平方米（22 平方呎）、工作平台 1.500 平方米（16 平方呎）。兩者已包含在實用面積中，不應重複加入。
3. **住宅樓面圖改為按單位顯示局部圖** — 現有594組有效座數／樓層／單位記錄對應64種不同樓層單位圖，從售樓說明書原整層平面圖裁切，並保留 PDF 原頁核查按鈕。**裁切圖片包含鄰近位置，不能當作正式分戶界線圖，也不可據此量度尺寸。**
4. **新的「售樓說明書圖則」分頁** — 包含 PDF 共26個圖則／圖例頁（位置／分區、布局、住宅樓面、天台、停車場、公共設施、橫截面及立面），可篩選、放大、連回 PDF 原頁。航拍照片不屬於「圖則」，且該售樓說明書明確註明部分航拍內容未經許可不得複製，因此未納入。
5. **天台圖則整合** — 從「我的單位」樓面圖頁的「天台圖則（僅供參考）」區塊移至獨立圖則頁；沒有刪除天台圖則內容。
6. **主選單** — 公契搜尋、公契圖則、我的單位、售樓說明書圖則四個入口。沿用原 GitHub Pages Repository。
