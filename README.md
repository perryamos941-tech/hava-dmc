# HAVA v2.5.5 — 資料準確性及版本管理

**上傳 GitHub Pages：** 將此資料夾的所有檔案及子資料夾複製到 `hava-dmc` Repository 根目錄，執行 Commit → Push。不要建立內層 v2.5.3 子資料夾。

## 本次變更
- 建立 `quality.html`：統一列出資料來源、日期概念、SHA-256、抽樣核對範圍、五個修訂數字格、DMC 法律譯文限制。
- `units.html`：移除舊版2025年標籤殘留；加入面積、電器、機電每筆資料的核對狀態與說明。
- 資料層新增 `auditStatus` 與可追溯的 `auditRef`，不以「整張表版本相同」代替逐格審核。
- 新增 `data/quality.json`/`data/quality.js` 版本資訊；所有主頁加入品質頁入口。
- 更新 Service Worker 版本及快取策略，減少混合舊版內容。
- 新增 `scripts/verify_release.py`，驗證來源指紋（若原PDF可用）、每筆來源頁碼、全部數量及五個修訂欄位。
