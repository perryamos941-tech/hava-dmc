# HAVA 業主資訊 · v2.6

本網站以 GitHub Pages 部署，讓業主查閱 HAVA 公契、售樓說明書、住宅圖則及按單位索引的設備資料。

## 公契資料的重要區分

- **繁體中文 DMC 文字**：直接取自使用者提供的98頁《SPH Site A DMC v9 engrossment clean-Chinese.pdf》。不是網站以AI生成的逐句譯文，也沒有重寫原文。
- **簡體中文**：由上述繁中文件文字程式轉換，並非另一份已簽署的法律文件。
- **英文原文**：查閱按鈕一律連到 HAVA 官網的87頁英文登記公契。英文搜尋 OCR 未完全人工核對。
- **中英差異提示**：已定位第8(c)、8(e)、10、13(a)及62條的5個差異位置；提示是獨立註解，不更改繁中原文。其他部分尚未完成英文／中文全文逐句核證。
- 中文文件正式登記、認證狀態尚未獨立查證；網站本身不是官方發布平台。

## 發布至 GitHub Pages

將 ZIP 直接解壓，把**全部檔案與子資料夾**放到既有 `hava-dmc` Repository 根目錄，覆蓋同名檔案。GitHub Desktop → Commit to main → Push origin。Repository 設定 Pages：`main`、`/(root)`。

網站主要入口：`index.html`、`chinese.html`、`units.html`、`drawings.html`、`quality.html`。
