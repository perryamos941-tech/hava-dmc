# HAVA v2.6.2 — 圖則下載及穩定性復核

此版本由 v2.6.1 更新，**不改動任何 DMC 條文、繁體中文來源資料、五處已確認中英差異、面積、電器或機電數值**。

## 下載方式

- **公契圖則**：在「公契搜尋 → 圖則查閱」每張卡片或高清瀏覽器按「下載圖則 JPG」，下載 `plans/plan-77.jpg` 至 `plans/plan-87.jpg` 中對應原尺寸圖片。
- **售樓說明書圖則**：在 `drawings.html` 每張卡片或放大視窗按「下載圖片」，下載 `brochure/drawing-{PDF頁碼}.webp` 的高清版本，共26張。
- **我的單位局部圖**：在 `units.html` 的「住宅樓面圖」分頁或放大視窗按「下載局部圖」，下載所選單位對應的 WebP 裁圖。
- 下載使用同源靜態圖片的原生 HTML `download` 屬性，不修改圖片內容；部分行動瀏覽器可能先顯示儲存位置選擇。PDF 原文對照按鈕仍保留。

**重要**：下載的是本站託管的圖片檔（售樓圖則 WebP、公契圖則 JPG），不是英文登記公契或售樓說明書的官方 PDF。單位局部裁圖不代表法律或測量上的分戶界線，圖則內容必須對照正式 PDF。公開重刊和再分發權限仍需由網站管理者確認。

資料來源：英文登記 DMC `HAVA_DMC_dd_20251125_Reg20251209.pdf`；繁中 DMC 取自使用者提供的98頁中文文件；售樓說明書 `SPHA_20260817.pdf`。
