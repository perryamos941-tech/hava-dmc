## 人手邏輯與文字座標交叉校對（2025版）

針對第1座（1A）、15樓E室的原始售樓說明書 PDF 第105頁（印刷第103頁）：

- 橫向欄位：Tower 1(1A) / 標準樓層組 / E；PDF座標x約961。
- 原PDF此欄有 **11個獨立 ✓**。
- 與網站列出的11筆適用型號記錄逐行比對，**11項均能配上同列的 ✓，沒有多列或漏列**。
- 兩款浴室寶 `FV-40BE3H2` 和 `FV-02NU1H` 均各有一個 ✓。
- 兩款東芝分體冷氣室內機 `RAS-M10N4KV`、`RAS-M22N4KV` 和一款室外機 `RAS-4M27S3AV-E` 均各有 ✓。
- 微波爐行原文為 `BE732L1B1B / BE732R1B1B`，此為原表合併列示，不能從這一行推定實際安裝左右哪一型號。
- 11指**適用型號行數**，不等於11件實物；浴室寶及冷氣出現多個型號不應以設備名稱重複為由刪除。
